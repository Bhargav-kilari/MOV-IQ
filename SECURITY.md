# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **MOV-IQ**, please do NOT create a public issue. Instead, report it directly to the maintainer:

- **Contact**: `kilaribhargavkrish123@gmail.com`

Please include:
1. Description of the issue
2. Steps to reproduce
3. Potential impact

We appreciate responsible disclosure and will address confirmed vulnerabilities swiftly.
